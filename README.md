# Apresentação Redecon

Apresentação comercial da Redecon Consórcios, baseada no Método API (Aquisição, Poupança e Investimento).

- Os dados (taxas, funil, textos, números institucionais) vêm da planilha **Apresentação Redecon – Dados**, no Google Drive.
- Sem internet, a apresentação usa os últimos dados salvos no aparelho.
- Para personalizar uma reunião: botão de pessoa na barra inferior (nome do cliente, apresentador, foco).
